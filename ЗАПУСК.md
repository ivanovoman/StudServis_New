# Как запустить у себя

Нужны **два** сервера. Node раздаёт сайт, Python делает разбор темы,
поиск источников и чтение PDF. Одного `npm start` не хватит: без Python
кнопка «Настройки» не сможет загружать файлы.

## Что поставить заранее

- Node.js 18 или новее — https://nodejs.org
- Python 3.11 или новее — https://python.org (при установке отметить
  галочку «Add Python to PATH»)

Проверка, что оба видны системе:

```
node -v
python --version
```

## Шаг 1. Зависимости (один раз)

В папке проекта:

```
npm install
pip install -r backend/requirements.txt
```

## Шаг 2. Ключ OpenRouter

Скопировать `.env.example` в `.env` и вписать свой ключ:

```
OPENROUTER_API_KEY=sk-or-v1-...
```

Ключ берётся на https://openrouter.ai/keys. Без него сайт откроется, но
генерация работать не будет.

Файл `.env` в git не попадает — он в `.gitignore`.

## Шаг 3. Запуск

Нужны **два окна терминала**, оба остаются открытыми.

**Окно 1 — Python:**

```
cd backend
python -m uvicorn app.main:app --port 8000
```

Должно появиться: `Application startup complete.`

**Окно 2 — Node:**

```
npm start
```

Должно появиться: `Студсервис запущен на http://localhost:3000`

## Шаг 4. Открыть

http://localhost:3000

Тема оформления выбирается случайно при каждом заходе. Открыть
конкретную:

```
http://localhost:3000/?theme=Windows_95.html
http://localhost:3000/?theme=Green_Phosphor.html
http://localhost:3000/?theme=amber-crt.html
```

Список всех тем — в папке `public/themes/`.

## Если что-то не так

**«Python-бэкенд недоступен»** при загрузке файла — не запущено окно 1.

**Порт 3000 занят** — `set PORT=3001 && npm start` (Windows) или
`PORT=3001 npm start` (Linux/macOS).

**`npm start` ругается на модуль** — не выполнен `npm install`.

**Ошибка 401 при генерации** — неверный ключ в `.env`.

**Кириллица в консоли Windows выглядит крякозябрами** — выполнить
`chcp 65001` перед запуском. На работу сайта не влияет.
