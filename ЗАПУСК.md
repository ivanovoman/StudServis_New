# Как запустить у себя

Нужны **два** сервера, оба работают одновременно:

- **Node** — раздаёт сайт и генерацию текста (порт 3000)
- **Python** — загрузка файлов, чтение PDF, поиск источников (порт 8000)

Без Python сайт откроется, но кнопка «Настройки» не сможет принимать
файлы.

## Что поставить заранее

- **Node.js 18+** — https://nodejs.org (обычный установщик, «Next → Next»)
- **Python 3.11+** — https://python.org
  При установке на Windows обязательно отметить галочку
  **«Add Python to PATH»**, иначе команды ниже не найдутся.

Проверка:

```
node -v
python --version
```

Если `python` не найден, попробуйте `py --version` — на Windows часто
работает именно так, и тогда во всех командах ниже пишите `py` вместо
`python`.

## Шаг 1. Скачать код

```
git clone -b devin/1786964976-backend-integration https://github.com/ivanovoman/StudServis_New
cd StudServis_New
```

Без git: на странице репозитория зелёная кнопка **Code → Download ZIP**,
затем распаковать и зайти в папку.

## Шаг 2. Зависимости

```
npm install
pip install -r backend/requirements.txt
```

Займёт пару минут. Python-пакетов примерно на 100 МБ.

Файл `backend/requirements-future.txt` ставить **не нужно** — там
зависимости модулей, которые ещё не написаны (Qdrant, Celery, ЮKassa).
Один из них тянет torch на два гигабайта.

## Шаг 3. Ключ OpenRouter

Скопировать `.env.example` в `.env`:

```
copy .env.example .env        (Windows)
cp .env.example .env          (Linux / macOS)
```

Открыть `.env` блокнотом и вписать ключ:

```
OPENROUTER_API_KEY=sk-or-v1-...
```

Ключ бесплатный, берётся на https://openrouter.ai/keys

Без ключа сайт откроется и файлы будут загружаться, но генерация текста
работать не будет.

## Шаг 4. Запуск

Нужны **два окна терминала**. Оба остаются открытыми, пока вы работаете.

**Окно 1 — Python:**

```
cd backend
python -m uvicorn app.main:app --port 8000
```

Признак успеха: `Application startup complete.`

**Окно 2 — Node** (из корня проекта):

```
npm start
```

Признак успеха: `Студсервис запущен на http://localhost:3000`

## Шаг 5. Открыть

**http://localhost:3000**

Тема оформления выбирается случайно при каждом заходе. Открыть
конкретную:

```
http://localhost:3000/?theme=Windows_95.html
http://localhost:3000/?theme=Green_Phosphor.html
http://localhost:3000/?theme=amber-crt.html
http://localhost:3000/?theme=ZX_Spectrum_Style_UI.html
```

Все 16 тем — в папке `public/themes/`.

## Как обновиться до свежей версии

Если проект уже скачан и вы хотите забрать последние правки.

### Вариант А. Скачивали через git clone

В папке проекта:

```
git pull
```

Всё. Ваш `.env` с ключом не тронется — он в `.gitignore` и git его не
трогает.

Если pull ругается `Your local changes would be overwritten` — значит вы
что-то правили в файлах проекта. Чтобы отбросить свои правки и взять
версию с GitHub:

```
git checkout -- .
git pull
```

### Вариант Б. Скачивали ZIP

`git pull` не сработает: в ZIP нет истории git. Проще перейти на клон
один раз и дальше обновляться одной командой:

```
git clone -b devin/1786964976-backend-integration https://github.com/ivanovoman/StudServis_New StudServis_New2
```

Затем скопировать `.env` из старой папки в новую и работать в новой.

### После обновления

Смотрите, что изменилось:

- менялся **только `api/server.js`** → перезапустить окно с `npm start`
  (Ctrl+C, потом снова `npm start`). Python трогать не нужно.
- менялось что-то в **`backend/`** → перезапустить окно с uvicorn.
- менялся **`package.json`** → выполнить `npm install`.
- менялся **`backend/requirements.txt`** → выполнить
  `pip install -r backend/requirements.txt`.

Посмотреть, что пришло с обновлением:

```
git log --oneline -5
```

## Если что-то не так

**«Python-бэкенд недоступен»** при загрузке файла
→ не запущено окно 1, или оно упало. Посмотрите, что там написано.

**`npm start` ругается на модуль**
→ не выполнен `npm install`.

**`python: command not found`**
→ на Windows попробуйте `py -m uvicorn app.main:app --port 8000`.

**`No module named uvicorn`**
→ не выполнен `pip install -r backend/requirements.txt`, либо pip
поставил пакеты в другой Python. Помогает `python -m pip install -r
backend/requirements.txt` — так пакеты точно уйдут в тот же Python.

**Порт занят**
→ `set PORT=3001 && npm start` (Windows) или `PORT=3001 npm start`
(Linux/macOS). Для Python: `--port 8001`, но тогда Node не найдёт его —
пропишите `PY_BACKEND_URL=http://127.0.0.1:8001` в `.env`.

**Ошибка 401 при генерации**
→ неверный ключ в `.env`.

**Крякозябры в консоли Windows**
→ выполните `chcp 65001` перед запуском. На работу сайта не влияет.
