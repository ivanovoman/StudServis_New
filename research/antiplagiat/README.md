# Пометки «ИИ» Антиплагиат.ВУЗ: что их вызывает

Данные: 10 отчётов заказчика (8 уникальных, 5 работ, 3 пары версий),
5 700 строк, 269 окон по ~1000 знаков, из них 76 помечены как ИИ.
Отчёты и тексты работ в репозиторий не входят (работы клиентов, `incoming/`).

## Как устроена разметка
- Розовые прямоугольники заливки RGB (1.0, 0.7, 0.79) под строками → `extract.py`.
- Помечаются **блоки ≈ 850–1000 знаков** (медиана одиночного блока ≈ 900),
  длинные куски — несколько блоков подряд. Не предложения.
- **Пометка зависит от контекста окна:** в паре 200592 — 24 предложения слово
  в слово одинаковы в обеих версиях, в одной помечены, в другой нет.

## Какие признаки различают (`features.js`, AUC внутри одной работы)
| признак | AUC | ИИ | не ИИ |
|---|---|---|---|
| цифр на 1000 знаков (нормы, даты, суммы, номера) | 0,33 → **0,67 в пользу человека** | 1,8 | 3,9 (медианы) |
| разброс длины предложений (CV) | 0,39 → 0,61 | 0,46 | 0,53 |
| разнообразие слов | 0,61 | | |
| детектор заказчика (pAI) | 0,57 | 0,61 | 0,61 |
| разговорность (сторож регистра) | 0,57 — в ИИ-окнах **чуть больше** | | |
| перплексия ruGPT-3 small (`perplexity.py`) | 0,59 | | |
| «суды без реквизитов», «компания А/Б», служебные фразы | ≈ 0,5 | | |

Признаки из скриншотов работы о ЕНС («суды указывают…» без акта, придуманные
сценарии, «логично перейти») на остальных работах **не подтвердились**.

Модели-приближения (обучение на 7 работах, проверка на 8-й): слова/символы
TF-IDF — 0,66–0,68; признаки + перплексия — 0,66. **Повторить Антиплагиат по
8 отчётам нельзя** — для предварительной проверки слишком слабо.

## Пары версий (`pairs.py`)
- 200577 (СК, 52 % → 4 %): из 223 помеченных предложений 148 удалены, 71
  переписаны — пометка снята почти со всех. Текст сокращён 54 → 22 тыс. зн.
  Было: общие утверждения учебника («Они определяют, как должны действовать
  следственные органы», «Единоначалие особенно важно…»). Стало: привязка к
  норме («№ 403-ФЗ», «[2, ст. 38]»); цифр в переписанных фразах 34 против 13.

## Где наш вывод (промпт C, 40 окон)

на стороне «не ИИ». Часть цифр — выдуманные нормы, это отдельный риск.
