# Как отправить код на GitHub

Всё готово к отправке: remote настроен, ветка совпадает с той, что на
GitHub, 18 коммитов ждут push. Нужен только доступ — у меня его нет.

Репозиторий: https://github.com/ivanovoman/StudServis_New
Ветка: `devin/1786964976-backend-integration`

## Вариант 1. Вы отправляете сами (проще и безопаснее)

Скачайте папку проекта, откройте в ней терминал и выполните:

```
git push origin devin/1786964976-backend-integration
```

Git спросит логин и пароль. Вместо пароля нужен **токен**, обычный
пароль GitHub с 2021 года не принимает.

Где взять токен:
GitHub → Settings → Developer settings → Personal access tokens →
Tokens (classic) → Generate new token → отметить галочку **repo**.

Или через GitHub Desktop / VS Code — там вход в один клик, токен
создаётся сам.

## Вариант 2. Вы даёте токен мне

Тогда я отправлю сам. Но учтите:

- токен даёт полный доступ к вашим репозиториям;
- всё, что написано в чат, считается скомпрометированным — ключ
  OpenRouter вы уже присылали открытым текстом, его надо перевыпустить;
- после push токен нужно сразу отозвать в настройках GitHub.

Если решите так — создайте токен с галочкой **repo** и **сроком жизни
7 дней**, чтобы он протух сам.

## Что уйдёт при push

18 коммитов поверх `de4b51e`, который на GitHub уже есть. Это обычный
fast-forward: ничего не перезаписывается, история не переписывается.

Основное:

- Python/FastAPI бэкенд: ГОСТ-движок, роутер моделей, схема БД
- Модуль 1: анализ темы с опорой на реальные публикации
- Поиск источников: OpenAlex + КиберЛенинка, дедупликация, релевантность
- Загрузка своих источников и методички (PDF/DOCX/TXT/MD/RTF)
- Калибровка ИИ-детектора: AUC 0.375 → 0.893
- Кнопка настроек и пункт «Речь для защиты» во всех 16 темах
- 331 тест

## Проверка перед отправкой

Секретов в коде нет, проверено:

- `.env` в `.gitignore`, гитом не отслеживается
- ключей OpenRouter нет ни в файлах, ни в истории коммитов

## Если push отклонён

`non-fast-forward` — значит, на GitHub появились новые коммиты. Тогда:

```
git pull --rebase origin devin/1786964976-backend-integration
git push origin devin/1786964976-backend-integration
```
