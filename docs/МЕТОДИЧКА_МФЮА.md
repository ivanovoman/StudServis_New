# Требования МФЮА (по присланной методичке)

Разобран файл `5359_методичка.pdf` — методические рекомендации по
подготовке и защите магистерской диссертации, кафедра
гражданско-правовых дисциплин, направление 40.04.01 «Юриспруденция»,
магистерская программа «Правовое обеспечение бизнеса». 32 страницы.

## Оформление (раздел 4.1)

| Требование | Методичка | У нас |
| --- | --- | --- |
| Шрифт | Times New Roman, 14 пт | совпадает |
| Интервал | 1,5 | совпадает |
| Абзацный отступ | 1,25 см | совпадает |
| Выравнивание | по ширине | совпадает |
| Поле сверху | 20 мм | совпадает |
| Поле снизу | 20 мм | совпадает |
| Поле слева | 30 мм | совпадает |
| **Поле справа** | **10 мм** | по умолчанию 15 мм, задаётся параметром |
| Сноски | TNR 12, одинарный, по ширине | сносок пока нет |

## Нумерация страниц (раздел 4.4)

* арабскими цифрами, без точки и прочих знаков;
* **правый нижний угол**;
* сквозная по всей работе;
* титульный лист считается первой страницей, **но номер на нём не
  ставится**;
* оглавление получает номер 2.

Сделано ровно так: номер вставляется полем PAGE, на титуле подавляется
флагом titlePg.

## Названия разделов

Методичка называет их иначе, чем принято по умолчанию:

* **«Оглавление»**, а не «Содержание»;
* **«Список используемых источников»**, а не «Список литературы».

Оба названия задаются параметрами при экспорте.

## Структура работы (раздел 3.1)

Титульный лист, оглавление, введение, основная часть (главы и
параграфы), заключение, список используемых источников, приложения.

Заголовки «Введение», «Заключение», «Оглавление» **не нумеруются**.
Нумерация параграфа — номер главы и номер параграфа через точку.

## Титульный лист (приложение 2)

Порядок блоков сверху вниз:

1. МОСКОВСКИЙ ФИНАНСОВО-ЮРИДИЧЕСКИЙ УНИВЕРСИТЕТ МФЮА
2. Кафедра
3. Направление / специальность, профиль / специализация
4. «К ЗАЩИТЕ (РЕКОМЕНДОВАНО / НЕ РЕКОМЕНДОВАНО)», заведующий кафедрой,
   дата
5. МАГИСТЕРСКАЯ ДИССЕРТАЦИЯ, «На тему:»
6. Обучающийся, подпись, дата
7. Индивидуальный номер (ИНС), группа
8. Руководитель (уч. степень, звание, инициалы, фамилия), дата
9. Москва – 20__

Реализовано с настраиваемыми полями: блок «К защите» включается
галочкой, потому что в курсовой его быть не должно.

## Чего мы пока не делаем

* **Объём 80–150 страниц** — наш конвейер рассчитан на курсовую;
  для диссертации нужны другие объёмы разделов (в ТЗ они не заданы).
* **Оригинальность не менее 60 %** — проверяется системой вуза, наш
  детектор оценивает другое (машинность текста, а не заимствования).
* **Задание, календарный план, отзыв, рецензия, архивный лист** —
  бланки из приложений 3–5, заполняются кафедрой и вручную.
* **Три обязательных приложения** — содержимое зависит от темы.
* **Апробация**: две публикации по теме исследования.

## Что стоит уточнить

Присланная методичка — **магистерская**. Если сервис делается прежде
всего для курсовых, нужна методичка по курсовой работе: там другой
титул, другой объём и обычно нет блока «К защите».
