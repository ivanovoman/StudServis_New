# Поставщики моделей: что делать, когда OpenRouter отвалился

## Сначала — точный диагноз

Сообщение «0 кредитов» на экране OpenRouter вводит в заблуждение. У этого
состояния три разные причины, и лечатся они по-разному. Проверить, какая
именно у вас, можно одной командой:

```bash
curl -s https://openrouter.ai/api/v1/key \
  -H "Authorization: Bearer ВАШ_КЛЮЧ"
```

| Что ответил сервер | Что это значит | Что делать |
| --- | --- | --- |
| `{"error":{"message":"User not found.","code":401}}` | Ключ мёртв: удалён, отозван или удалён сам аккаунт | Перевыпустить ключ на [openrouter.ai/keys](https://openrouter.ai/keys). **Покупка кредитов не поможет** |
| `{"data":{...,"limit_remaining":0}}` | Исчерпан суточный лимит | Подождать до сброса (00:00 UTC) или поднять лимит — см. ниже |
| Ошибка `402` при генерации | Баланс ушёл в минус | Пополнить до неотрицательного: минус блокирует даже бесплатные модели |

Проверка вашего текущего ключа из `.env` дала **401 `User not found`** —
то есть случай первый. Ключ нужно перевыпустить, деньги вносить не надо.

## Лимиты бесплатного тарифа OpenRouter

- 20 запросов в минуту — всегда.
- 50 запросов в сутки, если на счёт никогда не вносили деньги.
- 1000 запросов в сутки после разовой покупки кредитов на $10.

Ключевая деталь: порог в $10 срабатывает один раз и навсегда. Сами кредиты
на бесплатные модели не расходуются — это просто защита от регистрации
аккаунтов пачками. То есть $10 покупают не токены, а повышенный лимит
на всё время существования аккаунта.

Ещё две вещи, о которых легко забыть: неудачные запросы тоже списываются
из суточной квоты, и провайдеры постепенно убирают `:free`-версии
(у DeepSeek, Mistral и Gemini бесплатных вариантов на OpenRouter уже нет).
Поэтому опираться на один источник моделей рискованно.

## Варианты

| | OpenRouter | GigaChat (Сбер) | Свой сервер (Groq, Ollama…) |
| --- | --- | --- | --- |
| Бесплатный объём | 50 запросов/сутки, 1000 после $10 | 365 млн токенов на год | Зависит от сервиса |
| Из России | Нужен VPN | Без VPN | Как повезёт |
| Оплата | Иностранная карта | Российская карта | По-разному |
| Русский язык, право, ГОСТ | Средне | Лучше всех | Слабо у мелких моделей |
| Выбор моделей | Сотни | Четыре линейки | Одна-две |
| Скорость подключения | Минута | Полчаса (регистрация + сертификат) | Минута |

### Рекомендация для этого проекта

Основным поставщиком стоит сделать **GigaChat**, запасным — OpenRouter.

Причины три. Бесплатный объём несопоставим: 365 млн токенов в год против
50 запросов в сутки — одна курсовая расходует порядка сотни тысяч токенов,
то есть годового пакета хватает на сотни работ. GigaChat заметно лучше
держит русскую юридическую терминологию, ссылки на кодексы и требования
ГОСТ — а работы у нас юридические. И он не требует VPN и иностранной
карты, что снимает главный источник внезапных отказов.

Слабое место GigaChat — он один. Если Сбер поменяет условия, запасной
OpenRouter подхватит нагрузку автоматически.

## Как подключить GigaChat

1. Зайти на [developers.sber.ru/studio](https://developers.sber.ru/studio)
   и войти по Сбер ID (нужен российский номер телефона).
2. Создать проект **GigaChat API**, тип — «Физическое лицо».
3. В разделе с ключами нажать «Сгенерировать новый Client Secret» и
   скопировать строку **«Авторизационные данные»** — это Base64, длинная
   строка вида `NGE2...==`. Именно её, а не Client Secret по отдельности.
4. Вписать в `.env`:

```
LLM_PROVIDER=gigachat
GIGACHAT_AUTH_KEY=вставить_авторизационные_данные
LLM_FALLBACK_PROVIDER=openrouter
OPENROUTER_API_KEY=новый_ключ_openrouter
```

### Про сертификат

Серверы Сбера подписаны сертификатом Минцифры, которого нет в стандартном
хранилище Node. Без него запрос падает с `unable to verify the first
certificate`. Есть два пути.

Правильный — установить корневой сертификат в систему: скачать
`russiantrustedca.pem` со страницы
[Минцифры](https://www.gosuslugi.ru/crt) и указать Node на него:

```bash
export NODE_EXTRA_CA_CERTS=/путь/до/russiantrustedca.pem
npm start
```

Быстрый — отключить проверку сертификатов, добавив в `.env`:

```
GIGACHAT_INSECURE_TLS=1
```

Второй способ ослабляет защиту от подмены трафика. Для локальной разработки
это терпимо, при выкладывании на сервер — нет; сервер выведет
предупреждение в консоль, чтобы флаг не остался включённым незаметно.

## Как подключить что-то ещё

Провайдер `custom` работает с любым сервисом, говорящим на диалекте OpenAI.

**Groq** — очень быстрый, бесплатный тариф щедрый, но из России нужен VPN:

```
LLM_PROVIDER=custom
CUSTOM_API_URL=https://api.groq.com/openai/v1/chat/completions
CUSTOM_API_KEY=gsk_...
CUSTOM_MODELS=llama-3.3-70b-versatile,llama-3.1-8b-instant
```

**Ollama на своём компьютере** — бесплатно навсегда, без интернета и
лимитов, но нужна видеокарта, и качество на юридических текстах заметно
ниже облачных моделей. Для отладки промптов подходит хорошо, для готовых
работ — нет:

```
LLM_PROVIDER=custom
CUSTOM_API_URL=http://127.0.0.1:11434/v1/chat/completions
CUSTOM_MODELS=qwen2.5:14b
```

Ключ в этом случае не нужен.

## Проверка, что всё настроено

Запустите сервер и откройте <http://localhost:3000/api/health>. Ответ
покажет, каких поставщиков сервер видит и в каком порядке будет их
пробовать:

```json
{
  "ok": true,
  "providers": [
    {"id": "gigachat", "title": "GigaChat (Сбер)", "models": ["GigaChat-2-Max", "..."]},
    {"id": "openrouter", "title": "OpenRouter", "models": ["minimax/minimax-m3:free", "..."]}
  ]
}
```

Если `providers` пуст — ни один ключ не подхватился, проверьте `.env`.

## Как сервер выбирает модель

Порядок такой: поставщики перебираются в порядке
`LLM_PROVIDER` → `LLM_FALLBACK_PROVIDER`, внутри каждого — его модели по
списку. Первая, ответившая успешно, и отвечает пользователю.

Ошибки обрабатываются по-разному в зависимости от типа. `401` и `403`
означают проблему с ключом — остальные модели этого поставщика
пропускаются сразу, потому что ключ у них общий, и управление переходит
к следующему поставщику. `429` (упёрлись в лимит), `404` (модель убрали),
`400` и `5xx` — повод просто взять следующую модель. После полного круга
по всем поставщикам сервер ждёт 2,5 секунды и проходит круг ещё раз:
бесплатные модели часто отдают `429` пачкой, а через пару секунд отвечают
нормально.

Если не сработало совсем ничего, пользователь получает сводку с причиной
по каждому поставщику отдельно — например:

```
GigaChat (Сбер): ключ отклонён (401 Unauthorized);
OpenRouter: minimax/minimax-m3:free — 429 Rate limit exceeded
```

Так сразу видно, где именно чинить.
