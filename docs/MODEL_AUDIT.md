# Аудит бесплатных моделей OpenRouter

Дата проверки: **01.09.2026**. Проверено реальными запросами боевым ключом.

## Итог: список моделей в коде был нерабочим

В `api/server.js` было зашито 4 модели. Из них:

| Модель в старом коде | Реальность |
|---|---|
| `nvidia/nemotron-3-super-120b-a12b:free` *(стояла первой)* | Отдаёт **404** от Nvidia. Когда отвечает — пишет **по-английски**: «We need to produce 4 sentences...». Доля кириллицы **0.10** |
| `deepseek/deepseek-v4-flash:free` | **Не существует.** Такого id нет в каталоге OpenRouter |
| `google/gemma-4-31b-it:free` | Существует, но стабильно **429** — общий пул исчерпан |
| `moonshotai/kimi-k2.6:free` | **Не существует.** Такого id нет в каталоге |

Два id из четырёх были выдуманы, первая модель отвечала не на том языке.
Комментарий в коде утверждал, что nemotron «подтверждена рабочей 20.06.2026» — это не так.

## Как проверялось

18 free-моделей из каталога → запрос на русском юридическом тексте →
отсев по: доступности, доле кириллицы, наличию клише, разбросу длин
предложений (показатель живого ритма), ссылкам на нормы и практику.
Затем 3 повторных прогона на стабильность языка.

Результат: **11 из 18** вообще отвечают, из них пригодны для русской прозы — 5.

## Отдельно: галлюцинации подтверждены на практике

`poolside/laguna-s-2.1` выдал уверенный текст, где почти всё выдумано:

> «Федеральный закон **№208-ФЗ** «О несостоятельности (банкротстве)»... **Статья 3**
> этого закона... дело **№А40-15002/2019**... ООО «ТехноСервис»... ИП Петрова...»

Что не так:
- Закон о банкротстве — **127-ФЗ**, а 208-ФЗ — это «Об акционерных обществах»;
- КДЛ определено в **ст. 61.10**, а не в ст. 3;
- дело, компания и стороны — выдуманы.

`nemotron-ultra` сослался на **ст. 61.2** (это про оспаривание сделок, а не про
определение КДЛ) и выдал дело «№ А40-123456/2022» — номер-заглушка вида 123456.
Плюс сослался на «Парламентскую газету» как на источник правовой позиции.

**Вывод: модуль Sources & Verification из ТЗ — не опциональная роскошь.**
Без проверки ссылок сервис будет уверенно выдавать несуществующие нормы и дела,
и это прямой репутационный риск. Ни один free-промпт эту проблему не решает —
нужна перекрёстная проверка по внешним базам.

## Поддержка списка

Free-модели на OpenRouter меняются без предупреждения. Добавлен скрипт:

```bash
node scripts/check-models.js         # проверить рабочий список
node scripts/check-models.js --all   # проверить все free и предложить замену
```

Скрипт бьёт реальным запросом на русском, различает 404 (модель мертва) и
429 (временный лимит — делает повтор), считает долю кириллицы и отсеивает
модели, которые ушли в англоязычный reasoning. Возвращает ненулевой код
при поломке — можно повесить в CI или в крон.
