# Поставщики научной литературы: что проверено и что подключено

Дата проверки — 25 сентября 2026 года. Все кандидаты опрошены живыми
запросами из рабочего окружения, русскими и английскими. Проверялись три
вещи: пускает ли база вообще, знает ли она **русские юридические** темы
и отдаёт ли осмысленный абстракт (по коротким аннотациям в две строки
модель писать не может).

## Итог: подключено четыре базы

| База | Ключ | Что даёт | Доля в выдаче по юр. теме |
| --- | --- | --- | --- |
| **КиберЛенинка** | не нужен | русская периодика, **полные тексты** | 4–7 из 8 |
| **Crossref** | не нужен | точная библиография, DOI, русские абстракты | 2 из 8 |
| **OpenAlex** | бесплатный | мировая наука, цитируемость | 1–2 из 8 |
| **DOAJ** | не нужен | гарантированный открытый доступ, длинные абстракты | 0–1 из 8 |

Проверка на трёх темах («коллизии в праве», «субсидиарная
ответственность КДЛ», «цифровые права и смарт-контракты») даёт 8 из 8
релевантных записей за 2–4 секунды, из них половина с DOI.

### Почему именно эти

**КиберЛенинка** остаётся основой: только она отдаёт полный текст
статьи, а не аннотацию. Для русской гуманитарной темы это половина
качества работы.

**Crossref** — главное приобретение. Он регистрирует DOI и поэтому знает
почти всё, что вышло в журналах с настоящей редакцией, включая
ваковские: «Вестник МГПУ. Серия Юридические науки», «Law. Journal of the
Higher School of Economics». По запросу «коллизии в праве» — 1645 статей
с 2019 года. Абстракты бывают на 2000 знаков, длиннее, чем у
КиберЛенинки. И главное: из его метаданных собирается **список
литературы**, реквизиты которого модель иначе выдумывает.

**OpenAlex** с февраля 2026 требует ключ: анонимам оставили около сотни
запросов в сутки на всех сразу. Ключ бесплатный, получается за минуту,
и с ним база отвечает стабильно.

**DOAJ** даёт мало (по русскому праву — единицы записей), но то, что
даёт, точно откроется без платной стены и с абстрактом на 2–3 тысячи
знаков. Держать его единственным нельзя, в дополнение — полезно.

## Отклонённые кандидаты

| База | Что ответила | Почему не подключена |
| --- | --- | --- |
| **eLibrary.ru** | HTTP 403 | закрыта для машинного доступа, API только по договору |
| **РГБ** (search.rsl.ru) | HTTP 403 | то же; поиск только через браузер |
| **Semantic Scholar** | HTTP 429 на каждый запрос | без ключа не работает, ключ выдают по заявке с обоснованием |
| **CORE** | HTTP 429 | ключ по заявке; обещает 200+ млн работ, стоит вернуться, когда ключ будет |
| **Соционет** | соединение не устанавливается | судя по всему, проект заброшен |
| **Europe PMC** | HTTP 200, 12 175 «результатов» | медицина и биология; по запросу «legal collision» выдаёт статьи про ДТП и ветеринарную экспертизу |
| **arXiv** | HTTP 200 | физика, математика, программирование; по праву пусто |
| **OpenAIRE** | HTTP 200, но формат не разобран | агрегатор европейских репозиториев, ответ в тяжёлом XML-подобном JSON; дублирует то, что уже есть в OpenAlex и DOAJ |
| **Google Scholar** | — | публичного API нет, парсинг запрещён правилами и ловится капчей |

### Про Europe PMC и arXiv отдельно

Обе базы живые и бесплатные, но профильные. Подключать их «на всякий
случай» вредно: они принесут статьи не по теме, те займут места в
выдаче и попадут в промпт. Смысл появится, если сервис пойдёт за
пределы юридических и гуманитарных тем — тогда их стоит включать по
области работы, а не всегда.

## Что рядом, но это не литература

Отдельный класс источников, нужный именно юридическим работам:

* **publication.pravo.gov.ru** — официальный портал правовых актов.
  Отвечает (`/api/PublicBlocks` → 200), но требует разбора формата.
  Полезен для точных реквизитов НПА;
* **sudact.ru** — судебная практика, отвечает, но только HTML: нужен
  парсер;
* **consultant.ru** — уже используется, но не как поставщик литературы:
  из него берутся оглавления кодексов для сверки ссылок на статьи.

Это не научная литература, и в список литературы они идут отдельными
разделами. Подключать их имеет смысл вместе с задачей «список
литературы по ГОСТ», а не сейчас.

## Как устроено в коде

Каждая база — отдельный модуль в `app/modules/sources/` с одинаковым
видом функции `find_sources(query, directions, min_year, limit)`,
возвращающей общий `Source`. Реестр `registry.py` опрашивает их
параллельно, сливает по нормализованному заголовку, ранжирует общим
ключом и придерживает пару мест для баз, проигравших по релевантности —
иначе русскоязычные заголовки вытесняют всё остальное подчистую.

Отказ любой базы не роняет поиск, но **обязательно пишется в лог**.
Молчаливый ноль неотличим от честного «по теме ничего не написано» —
именно так OpenAlex полгода выглядел работающим, не отдавая ничего.
