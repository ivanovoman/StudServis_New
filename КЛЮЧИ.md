# Какой ключ взять и где

Сервис сам ничего не придумывает — текст пишет облачная языковая модель,
к которой нужен доступ по ключу. Ключ бывает трёх видов, достаточно
**одного любого**.

Коротко, если некогда читать: **берите GigaChat**, он бесплатнее всех и
работает из России без VPN. OpenRouter — если VPN есть и хочется
подключиться за минуту.

---

## Сравнение

| | GigaChat (Сбер) | OpenRouter | Своя Ollama |
| --- | --- | --- | --- |
| Сколько бесплатно | **365 млн токенов на год** | 50 запросов в сутки | Без ограничений |
| Хватит примерно на | сотни курсовых | 5–6 курсовых в сутки | сколько угодно |
| Из России | **без VPN** | нужен VPN | локально |
| Что нужно для регистрации | Сбер ID, номер РФ | почта | видеокарта |
| Время на подключение | ~30 минут | ~2 минуты | ~1 час |
| Русское право и ГОСТ | **лучше всех** | средне | слабо |
| Деньги | не нужны | не нужны | не нужны |

Одна курсовая расходует порядка ста тысяч токенов. Отсюда и разница:
годового пакета Сбера хватает надолго, а 50 запросов OpenRouter — это
примерно 5–6 полных работ в сутки, потому что каждый шаг (анализ, план,
введение) — отдельный запрос.

## Вариант 1. GigaChat — рекомендую

**Что получаете бесплатно** (проверено на официальной странице тарифов
5 сентября 2026):

| Модель | Бесплатных токенов | Срок |
| --- | --- | --- |
| Lite (`GigaChat-2`) | 250 млн | 12 месяцев |
| Pro (`GigaChat-2-Pro`) | 40 млн | 12 месяцев |
| Max (`GigaChat-2-Max`) | 25 млн | 12 месяцев |
| Ultra (`GigaChat-3-Ultra`) | 50 млн | 12 месяцев |

Итого 365 млн. Карта не нужна, платить ничего не надо.

> В блогах часто попадается цифра «1 млн токенов в год» — она устарела
> в 365 раз. Верить только официальной странице тарифов.

**Как получить ключ**

1. Зайти на <https://developers.sber.ru/studio> и войти по **Сбер ID**
   (нужен российский номер телефона).
2. Создать проект **GigaChat API**, тип — **«Физическое лицо»**.
3. Открыть «Настройки API» → **«Получить ключ»**.
4. Скопировать строку **«Авторизационные данные»** — длинная строка
   Base64 вида `NGE2Y2...==`.

**Тут легко ошибиться.** Нужны именно «Авторизационные данные»
(это Client ID и Client Secret, слитые вместе и закодированные), а
**не** Client Secret сам по себе. Вставите Secret — получите `401`.

5. Вписать в файл `.env` в корне проекта:

```
LLM_PROVIDER=gigachat
GIGACHAT_AUTH_KEY=сюда_вставить_авторизационные_данные
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_INSECURE_TLS=1
```

**Зачем последняя строка.** Серверы Сбера подписаны сертификатом
Минцифры, которого нет в стандартном наборе Node — без него запрос
падает с `unable to verify the first certificate`. Строка отключает
проверку сертификата. Для работы на своём компьютере это приемлемо.

Правильнее — установить сертификат: скачать `russiantrustedca.pem` с
<https://www.gosuslugi.ru/crt> и запускать так:

```
set NODE_EXTRA_CA_CERTS=C:\путь\russiantrustedca.pem   (Windows)
export NODE_EXTRA_CA_CERTS=/путь/russiantrustedca.pem  (Linux/macOS)
npm start
```

Тогда строку `GIGACHAT_INSECURE_TLS=1` из `.env` уберите.

**Ограничение:** генерация идёт в один поток — два шага одновременно не
запустятся. Для одного пользователя незаметно.

## Вариант 2. OpenRouter — быстро, но с VPN

**Что получаете:** 50 запросов в сутки, 20 в минуту, бесплатно, без
карты. Доступ к 25+ моделям разных разработчиков сразу.

**Как получить ключ**

1. Зарегистрироваться на <https://openrouter.ai> (нужен VPN — из России
   сайт не открывается).
2. Открыть <https://openrouter.ai/keys> → **Create Key**.
3. Скопировать строку вида `sk-or-v1-...` — **она показывается один
   раз**, потом только перевыпуск.
4. Вписать в `.env`:

```
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ
```

**Что стоит знать про лимит.** Неудачные запросы тоже съедают квоту:
модель ответила ошибкой — минус один из пятидесяти. Разовая покупка
кредитов на $10 поднимает лимит до 1000 запросов в сутки **навсегда**,
причём сами кредиты на бесплатные модели не тратятся — это просто
проверка, что аккаунт не одноразовый. Нужна иностранная карта.

## Вариант 3. Ollama на своём компьютере

Бесплатно навсегда, без интернета, без лимитов и без регистрации. Но
нужна видеокарта, а качество на юридических текстах заметно ниже
облачных моделей — для отладки годится, для готовых работ нет.

1. Поставить <https://ollama.com>
2. `ollama pull qwen2.5:14b`
3. В `.env`:

```
LLM_PROVIDER=custom
CUSTOM_API_URL=http://127.0.0.1:11434/v1/chat/completions
CUSTOM_MODELS=qwen2.5:14b
```

Ключ не нужен.

## Два поставщика сразу — лучший вариант

Если кончились бесплатные токены у одного, сервер сам перейдёт ко
второму. Ничего не сломается и не остановится:

```
LLM_PROVIDER=gigachat
GIGACHAT_AUTH_KEY=...
GIGACHAT_INSECURE_TLS=1

LLM_FALLBACK_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-...
```

Порядок перебора: сначала `LLM_PROVIDER`, потом
`LLM_FALLBACK_PROVIDER`, внутри каждого — его модели по списку. Первая
ответившая и отвечает пользователю.

## Куда вписывать ключ

В корне проекта, рядом с `package.json`, должен лежать файл `.env`.
Если его нет — скопируйте образец:

```
copy .env.example .env    (Windows)
cp .env.example .env      (Linux / macOS)
```

Откройте блокнотом и впишите строки из нужного варианта выше.

**Частая ошибка на Windows:** блокнот дописывает `.txt`, и получается
`.env.txt` — сервер такой файл не увидит. В Проводнике включите
«Расширения имён файлов» и проверьте.

Файл `.env` в `.gitignore` — при обновлении через `git pull` он не
затрётся, и в репозиторий ключ не уедет.

---

## Проверить, что ключ подхватился

Запустите `npm start` и откройте <http://localhost:3000/api/health>

```json
{"ok":true,"providers":[{"id":"gigachat","title":"GigaChat (Сбер)","models":["GigaChat-2-Max","..."]}]}
```

- Список не пуст — ключ прочитан.
- `"providers":[]` — не прочитан: проверьте имя файла и что он в корне.

Эта страница показывает только то, что сервер увидел ключ. Живой ли он —
покажет первая генерация.

## Если что-то пошло не так

| Ошибка | Что значит | Что делать |
| --- | --- | --- |
| `ключ отклонён (401)` | Ключ недействителен | GigaChat: вставили Client Secret вместо «Авторизационных данных». OpenRouter: ключ отозван — перевыпустить. Деньги вносить не нужно |
| `429` / `упёрлись в лимит` | Кончилась квота | Подождать сброса или подключить второго поставщика |
| `unable to verify the first certificate` | Нет сертификата Минцифры | Добавить `GIGACHAT_INSECURE_TLS=1` в `.env` |
| `402` | Баланс OpenRouter в минусе | Пополнить: минус блокирует и бесплатные модели |
| `providers: []` | Ключ не прочитан | Проверить, что файл `.env`, а не `.env.txt`, и лежит в корне |
| Сайт OpenRouter не открывается | Блокировка | Нужен VPN, либо берите GigaChat |

`docs/LLM_PROVIDERS.md`. Установка и запуск — в `ЗАПУСК.md`. Сценарий
проверки — в `ПРОВЕРКА.md`.
